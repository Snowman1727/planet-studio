## Design Decisions

Use camera distance, not FOV or CSS scaling: raycasting and renderer dimensions
then remain correct. Zoom is 0.65–1.8, defaults to 1, and the minimum camera
distance is 9.7 / 1.8 (>5.38), outside all terrain and decoration geometry.
Close zoom may intentionally crop the silhouette, but never enters the globe.
PNG retains Day 02's automatic whole-planet framing independently of editor zoom.

Keep schema 2 with an additive optional `view.zoom`: absent fields in schema 1/2
migrate to 1; explicit non-finite, nonnumeric, null or out-of-range values reject.
No reinterpretation of existing coordinates, objects or history.

Use minus/plus Lucide icon buttons and a fixed-width percentage reset button.
Wheel affects only the canvas, normalizes pixel/line/page deltas, and cancels a
current uncommitted stroke first. Second touch similarly rolls back a stroke,
starts pinch from current zoom and suppresses painting/rotation until every
touch is released. Cancel, lost capture, blur and hidden document clear gestures.
Controls, canvas +/-/0 keys and gestures work in preview and offline player.

## Review Focus

- One finger remaining after pinch must not resume drawing or rotation.
- Cancel/blur/replace must not leave stale captured touch state.
- Undo/redo after zoom must preserve the latest view and redo branch.
- Aspect/resize changes must keep zoom and camera safely outside the globe.
- HTML export must contain real local controls and work without network access.
