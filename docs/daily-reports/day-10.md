## 交付内容

画布视图控件新增「物件列表 / Object list」入口。原生弹窗列出物件类型、
完整 ID 和锁定状态，可按六种类型筛选，并叠加去除首尾空白、
不区分大小写的 ID 字面子串搜索。空星球与无匹配结果分别显示，
每页最多 24 行，全部 2,000 个物件可通过 84 页或搜索访问。
重新打开弹窗保留搜索、筛选和页码；项目替换时清空这些临时状态。
删除、撤销或过滤后的越界页码自动收敛。

点击、键盘 Enter 或触屏点按一行，关闭弹窗并进入现有选择模式，
冻结旋转、保留缩放，将物件移至正面并交给现有属性面板。
星球背面的物件和锁定物件也能定位；定位不解锁、不改物件、
不增加编辑历史，也不清空已有撤销重做。
打开列表会取消尚未完成的拖动等手势，并退出预览。
渲染失败时仍可浏览、搜索和导出 JSON，但禁用定位。

中英文、原生键盘焦点和移动端均适配；64 字符 ID 在列表行内换行，
动态数据以文本插入，不解释为 HTML。
保持 schema 2，旧 schema 1/2 项目无需迁移。
列表筛选、页码和选择不进入存档；仅定位后的视角通过现有路径保存，
JSON、草稿恢复、本地作品库和独立离线 HTML 均保留该视角及原始物件。
导出的 HTML 不包含编辑器物件列表。
保留 2,000 物件、40 步历史、2 MB 导入和 MIT 约束。

新增独立查询/视角辅助模块、弹窗绑定模块和 6 项测试；集成主流程、
双语文案、样式、页面及两份 README。未修改博客，未开始混合生态画笔。

本次决策及代价：

- 沿用用户批准的原目录 main 发布流程，不新建工作树或重复确认；
  fresh fetch 和正常推送保护并发变更，若冲突须停止处理。
- 采用每页 24 行的显式分页，不引入虚拟列表；
  保持有界 DOM 和原生键盘/触屏交互，代价是远处条目需搜索或翻页。
- 保持现有 ±1.5 俯仰界限和固定 -0.04 滚转，避免改动存档及镜头契约；
  极点锚点距精确中心可能仍有约 4 度偏差。
- 列表条件和选择仅临时保留，只保存视角；与现有编辑状态一致，
  代价是重新打开项目后需重设筛选。

持久忽略规则。所列 Impeccable 技能文件在本机缺失，依据 `PRODUCT.md`
