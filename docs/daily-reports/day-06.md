## 交付内容

工具栏新增本地作品库入口。可主动保存多个星球，打开、重命名、复制、
确认删除；列表显示环境、物件数、更新时间和本次正在编辑的作品。
保存更新本次打开的条目，另存为新作品生成独立副本。打开作品复用未保存
修改保护，可取消或先下载 JSON。删除存档不会清空画布，重命名也不丢弃
独立修改过的画布名称或物件。

作品库使用独立的 `planet-studio:library:v1` 键，保存经过校验的完整
schema 2 快照，不修改单项目格式，不自动迁移或删除旧草稿。
schema 1、视角收藏、缩放、JSON 往返、笔画撤销重做和离线 HTML 保持兼容。
刷新恢复的草稿不绑定已有作品 ID，主动保存时新建条目，避免覆盖错误作品。
复制的是已保存快照；另存为新作品才保存当前画布。

写入由 Web Locks 串行化，等待前捕获版本，持锁后再次核对。
其他标签页更新会解除当前存档关联并取消过时的重命名/删除确认；
确认打开前重新验证所选快照。容量不足、存储禁用、损坏/未知版本集合、
缺失记录或竞争冲突均有中英文错误提示，不清空或覆盖旧数据。
不支持安全加锁的浏览器仍可读取和导出 JSON，但拒绝写入作品库。

改动文件：`prototype/studio/library.js`、`library-ui.js`、`main.js`、
`i18n.js`、`style.css`、`prototype/index.html`、两份 README、
`tests/studio-library.test.js` 及当日技术方案。
博客仓库未修改。

## 审查与边界

独立只读审查发现并发丢写、等待确认时使用旧快照、重命名覆盖独立草稿标题
三个问题，均有失败复现和修复后的回归证据；没有遗留的重要审查问题。

决策：仅在独立星球仓库执行已授权的 main 发布；不复制脏画布而复制存档；
刷新草稿不保持活动 ID；没有安全锁时拒绝写入而保留 JSON；云同步和生成
缩略图不属于本功能。相应代价是旧浏览器/非安全来源需要 JSON 备份，刷新
草稿主动保存可能产生新条目，数据不跨设备。

作品仅存于当前浏览器与站点，清理站点数据会删除作品库与草稿。需要长期
保存的内容应下载 JSON。英文列表在仅一个作品时仍显示复数 `projects`，
属于不影响操作的待打磨文案。浏览器验收为 Chromium，不代表 Safari、
Firefox 或手机实机验证。
