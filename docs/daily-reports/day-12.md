## 交付内容

工具区新增「画笔预设 / Brush presets」。将六种单一画笔或混合生态画笔的
类型、范围、密度和三个原始配比权重命名保存，列表点击即可恢复配置。
支持独立重命名、删除确认、键盘与触屏操作，刷新后保留。
保存只新增独立快照，不会覆盖同名项；名称去除首尾空白，不区分大小写且不能重复。
范围为整数 7–35 度，密度为 10–100%（步长 5），配比为整数 0–100，至少一种非零。
显示归一化百分比，保存原始权重，例如 6:3:1 不会变成 60:30:10。

原生管理弹窗包含当前配置摘要、名称输入、预设列表及状态反馈；
空白、非法配置、达到上限、存储失败和多标签页冲突均有双语状态。
选择、橡皮和旋转模式可以管理或应用预设，但不能保存新预设。
渲染故障时禁止保存与应用，仍允许重命名、删除以及作品 JSON 备份。
写入期间禁用相关控件并阻止 Escape 关闭，结束后恢复焦点。
用户名称使用 `textContent`，HTML 外观的名称也只显示为普通文本。

独立版本 1 集合使用 `planet-studio:brush-presets:v1`，最多 24 项、
名称 1–40 字符、总量 64 KiB（按 UTF-8 字节计算）。
解析时校验集合版本、数量、ID、时间、名称唯一性与全部配置。
无法读取、超大或损坏的数据不会被静默重建、覆盖或部分应用。
写入沿用作品库的独占 Web Locks 与原始字节版本检查：
等待锁之前捕获版本，之后的列表刷新不能授权覆盖其他标签页的新内容。
不支持安全锁、存储被阻断、配额不足或并发冲突时明确拒绝写入。

打开管理器取消未完成的笔画或拖动，并沿现有路径退出预览。
应用前校验整个配置，随后更新模式、滑杆和数值，不修改完成的景物或历史分支。
预设独立于草稿与作品库，不写入 JSON 或独立 HTML，不引入后端、依赖或格式迁移。
最终绘制的物件仍精确保留位置、朝向、大小和锁定状态；兼容 schema 1/2，
保持 2,000 物件、40 步历史、2 MB 导入及 MIT 声明。
未修改博客，未开始 Day 13。

主要文件：新增 `brush-presets.js`、`brush-presets-ui.js`、
`tests/studio-brush-presets.test.js`；集成到 main、i18n、HTML、CSS 和中英文 README。

## 审查与决策

独立新上下文只读审查覆盖整个功能提交、规格、方案、全部决策、相邻集成路径、
QA 脚本与日志，并检查四张代表截图。审查者独立运行 Node24 完整 **143/143**
测试及 whitespace 检查，没有 Critical、Important、Minor 或未判断项，无需修复。

本次决策及代价：

- 沿用用户授权的原目录 main 开发与发布，不重复确认或新建工作树；
  fresh fetch 与正常推送保护并发变更，代价是发现未知冲突时必须停止。
- 预设作为当前站点的本地数据，独立于作品与播放器，避免格式变化或意外分享配置；
  代价是预设不随 JSON 搬迁、不跨设备同步，清除站点数据会删除它们。
- 限制 24 项、40 字符和 64 KiB，并要求 Web Locks 写入，保证界面有界及并发安全；
  代价是超限必须先删除，缺少锁支持的浏览器不能保存预设。
- 快照包含绘画模式，非绘画工具只能管理和应用，避免保存擦除或选择状态；
  代价是保存之前必须切换到绘画工具。

没有延后的 Minor 问题。
